# Приклади коду до Лекції 14

Використовуйте цю папку для прикладів:

- Шаблон опису графа graph.md (вузли / ребра / спільний стан / правила маршрутизації)
- Шаблон промпту ролі вузла node-prompt.md
- Шаблон правил маршрутизації routing-rules.md
- Еталонна реалізація maker_checker_graph.py (прив'язана до фреймворку: LangGraph): перетворює шість кроків «Побудуйте свій перший граф з нуля» на працюючий код — схема стану, вузли, ребра, умовна маршрутизація, checkpointer. Основний текст лекції не залежить від фреймворку; це один зі способів записати його конкретно
- Приклади скриптів керування графом (виконання графа, перевірка checkpoint, запуск схвалення людиною)
